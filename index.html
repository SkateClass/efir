Источник и качество

Источники дополняются из API и M3U. Сохранённые адреса не удаляются при обновлении. Метки региональных версий и требований специальных заголовков видны в списке; браузер не подделывает такие заголовки.

Сохранить рабочие источники

На устройстве с рабочей версией 0.10 выполните «Экспорт настроек», затем импортируйте JSON здесь. Импорт объединяет адреса, а не заменяет их. Это единственный способ перенести именно ваши сохранённые рабочие источники: их нет в новом HTML автоматически.

Радиоподборки

В разделе «Радио» выберите Comedy Radio, хип-хоп/рэп, джаз, соул, фанк, американское ретро, китайские или европейские станции. Для иностранных жанров дополнительно выберите «Зарубежные». Каталог использует жанровые метки, страну и язык; это не заранее проверенные плейлисты. Новые страницы загружаются по кнопке. Ранее загруженное и избранное сохраняются.

Управление и производительность

Удерживайте ⠿ для перестановки. В горизонтальном режиме тяните влево/вправо, в вертикальном — вверх/вниз; Alt + стрелки работает с клавиатуры. Архив — с подтверждением. «Запомнить» закрепляет источник в избранном.

Один активный поток. Список показывается порциями до 150 элементов. Просмотренное видео не сохраняется в настройки или файлы. Браузер и встроенные плееры сами управляют кэшем. Анимация радио приостанавливается на паузе и в скрытой вкладке.
