Ваши каналы

Импортируйте JSON из рабочей версии 0.10. Будут перенесены каналы, радио, избранное, источники, порядок и архив. Новый файл не содержит автоматически каталог, сохранённый на другом устройстве.

Вид списка

Кнопка вида рядом с ТВ/радио переключает горизонтальные карточки и вертикальный список. Вид запоминается. Прокручивается только каталог: видео и управление остаются на месте. В широком режиме список расположен справа от видео.

Для перестановки удерживайте ⠿. В горизонтальном виде тяните влево/вправо, в вертикальном — вверх/вниз. Кнопка архива требует подтверждения. На клавиатуре Alt + стрелки на ручке меняет порядок.

Производительность и радио

Один активный поток. На странице до 150 строк/карточек, больше — по кнопке. Радио мира подгружается страницами по 100 станций. Без изображения у прямого радиопотока — декоративная анимация. На паузе и в скрытой вкладке она останавливается.

Видео не сохраняется в настройки и файловое хранилище приложения. Кэшем браузера и RUTUBE полностью управлять нельзя. Короткий HLS-буфер освобождается при переключении.

О мобильной версии

Блок телепрограммы убран. Данные привязки EPG из экспорта сохраняются для обратного переноса, но расписание не загружается. Для запуска локального HTML нужен браузер с JavaScript, а не предпросмотр. Для Android APK можно заменить asset index.html этим файлом и пересобрать проект; HTML сам не является APK.

В Android-оболочке предыдущего проекта кнопки Пауза и настройки совместимы с новым интерфейсом. Для фонового радио отдельная служба не реализована.
